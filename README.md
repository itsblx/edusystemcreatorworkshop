# EDUSYSTEM CREATOR WORKSHOP

Landing page rasmi untuk **EDUSYSTEM CREATOR WORKSHOP**.

## Kandungan

- `index.html` - landing page lengkap dengan Tailwind CSS, animasi, responsive layout, CTA ToyyibPay, FAQ, dan contact WhatsApp.
- `.nojekyll` - memastikan GitHub Pages publish fail static tanpa pemprosesan Jekyll.
- `.gitignore` - mengecualikan fail sistem/editor yang tidak perlu dimasukkan ke GitHub.

## Publish Ke GitHub Pages

1. Cipta repository baru di GitHub.
2. Upload semua fail dalam folder ini ke root repository.
3. Pergi ke `Settings` > `Pages`.
4. Pada bahagian `Build and deployment`, pilih:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Simpan tetapan dan tunggu GitHub Pages deploy.
